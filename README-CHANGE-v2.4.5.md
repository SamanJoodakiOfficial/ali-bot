# تغییرات نسخه ۲.۴.۵ — ریست کامل حجم و After First Use

- تمدید فقط یک ماه تقویمی از زمان تأیید؛ روزهای قبلی حذف می‌شود.
- حجم جدید به سقف قبلی اضافه نمی‌شود، بلکه جایگزین آن می‌شود.
- مصرف آپلود و دانلود با API رسمی ریست می‌شود و پس از تأیید صفر، بدهی فقط برای حجم خرید جدید ثبت می‌شود.
- در صورت خطا، عملیات به بررسی مدیر رفته و خودکار دوباره اجرا نمی‌شود.
- حساب‌های جدید با مدت **۳۰ روز پس از اولین استفاده** ساخته می‌شوند (`expiryTime=-2592000000`)، نه تاریخ انقضای ثابت از زمان ساخت.
- انقضای حساب‌های تازه‌ساخته‌شده در منو با عنوان «پس از اولین استفاده: ۳۰ روز» نمایش داده می‌شود.
- هیچ تنظیمی در `.env` و هیچ تغییری در ساختار SQLite لازم نیست.
- سوابق و عملیات معلق نسخه‌های قدیمی محفوظ می‌مانند.

**محدودیت:** ۳۰ روز بعد از اولین استفاده یک مدت ثابت است و الزاماً برابر یک ماه تقویمی نیست. اگر خود سنایی گره‌های متعددی دارد باید همگام‌سازی تأخیر شروع را در نسخه پنل واقعی بررسی کنید.

**امنیت مالی:** API ویرایش و API ریست در دو درخواست مجزا هستند. اگر یکی نامطمئن باشد، بدهی ثبت نمی‌شود؛ مدیر باید ابتدا وضعیت پنل را کنترل کند.
